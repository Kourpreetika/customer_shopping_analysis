# Customer Shopping Behaviour Analysis

## Project Overview
An end-to-end data analytics project focused on understanding customer shopping behaviour, purchasing patterns, and business trends using Python, SQL, Excel and Power BI.

## Objectives
- Analyze customer purchasing patterns.
- Understand customer preferences and shopping trends.
- Identify important business insights using SQL.
- Visualize key performance indicators through dashboards.

## Technologies Used
- Python
- Pandas
- Jupyter Notebook
- SQL
- PostgreSQL
- Power BI
- Microsoft Excel

## Project Structure
- `notebooks/` – Python data analysis and exploratory data analysis.
- `sql/` – SQL queries for customer behaviour analysis.
- `archive/` – Additional project datasets.
- `cleaned_customer.csv` – Processed customer dataset.
- `customer_behavior_dashboard.pbix` – Power BI dashboard.
- PDF and PPTX – Project documentation and presentation.

## Workflow
1. Data collection and understanding.
2. Data cleaning and preprocessing.
3. Exploratory data analysis using Python.
4. SQL-based business analysis.
5. Dashboard development and visualization.
6. Interpretation of findings.

## Key Insights
Refer to the project notebook, SQL queries and Power BI dashboard for the detailed analytical findings.

## How to Run
1. Clone this repository.
2. Install the required Python libraries.
3. Open the Jupyter notebook.
4. Execute the analysis cells.
